# 代码量统计工具

一个 Windows 桌面小程序，递归扫描指定目录，按语言统计 **文件数、空行、注释行、代码行**。

支持的语言：C、C++、Java、Python。

## 直接运行（不用编译）

打开 `bin` 文件夹，双击 `统计代码量.exe` 即可运行。

## 自己编译

前提：已安装 Visual Studio 2022，并勾选「使用 C++ 的桌面开发」工作负荷。

双击 `build.bat`，脚本会自动调用 MSVC 编译，完成后可执行文件输出到 `bin\统计代码量.exe`。

## 使用方法

1. 运行程序后，顶部输入框填入要统计的文件夹路径；也可以点「浏览...」选择目录。
2. 路径留空时默认统计程序当前所在目录。
3. 点「开始统计」，表格中按语言显示文件数、空行、注释行、代码行，最后一行为合计 `TOTAL`。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `源.cpp` | 全部源代码（Win32 图形界面程序） |
| `build.bat` | 一键编译脚本 |
| `bin\统计代码量.exe` | 预编译好的可执行文件 |
