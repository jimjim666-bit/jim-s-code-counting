# 代码量统计

递归扫描指定目录，统计 C、C++、Java、Python 各语言的文件数、空行数、注释行数、代码行数。

## 运行

打开 `bin` 目录，双击 `统计代码量.exe`。

## 编译

安装 Visual Studio 2022，勾选使用 C++ 的桌面开发，然后双击 `build.bat`，生成 `bin\统计代码量.exe`。

## 使用

1. 输入要统计的目录路径，或点「浏览...」选择；路径留空时统计程序所在目录。
2. 点「开始统计」，表格按语言显示各项数量，最后一行 `TOTAL` 为合计。

## 文件

| 文件 | 说明 |
| --- | --- |
| `源.cpp` | 源代码 |
| `build.bat` | 编译脚本 |
| `bin\统计代码量.exe` | 可执行文件 |
